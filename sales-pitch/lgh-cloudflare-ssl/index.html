補充議題與備詢

此區不在簡報主流程，按 Q 或 Esc 關閉。
Q1*.leehospital.com.tw 涵蓋哪些名稱？
A主網域下第一層的所有名稱，例如 his.leehospital.com.tw、dajia.leehospital.com.tw；兩層以上（如 a.his.leehospital.com.tw）不涵蓋。申請時會一併加入 leehospital.com.tw 本身。
Q2Cloudflare 的 API 金鑰外流怎麼辦？
A金鑰只能管理 DNS 記錄，而且限定官網主機的 IP 才能使用，在其他地方拿到也無法操作。貴院可隨時在 Cloudflare 後台撤銷並重新發行。
Q3院內電腦會信任 Let's Encrypt 的憑證嗎？
A主流瀏覽器與 Windows 都信任 Let's Encrypt。無法連外自動更新根憑證的電腦，以 GPO 派發 ISRG Root X1（及 ISRG Root YR、YE）即可。
Q4較舊的 Windows Server 能用嗎？
A我們會產生相容舊版 Windows 的 PFX 格式，並使用相容性最好的 RSA 2048 金鑰。作業系統過舊、已停止支援的主機，需個別確認是否能使用。
Q5廠商提供的系統（例如 HIS）怎麼換憑證？
A依各廠商的說明匯入。除了 PFX，我們也能提供 PEM 格式（憑證、中繼憑證、私鑰分開的檔案），供 Java 等系統使用。
Q6院內 DNS 的副本多久要同步一次？
A只有對外記錄變更時才需要同步，例如官網主機更換 IP。官網主機 IP 固定，平時不需要調整。
Q7Cloudflare 本身故障怎麼辦？
ACloudflare 的網路分散在全球 300 多個城市，單一地點異常會由其他節點接手。真有大範圍異常時，可暫時把官網改為不經代理、直接連到官網主機，主機本身也具備有效憑證。
Q8為什麼不直接購買 wildcard 憑證？
A購買的憑證同樣受最長效期限制（目前 200 天，2027/3/15 起 100 天），每次到期都要人工更換。自動化申請可以省下這些作業，也不需要採購費用。
Q9切換名稱伺服器要多久生效？
A通常數小時內陸續生效，最長約 48 小時。因為新舊 DNS 回答一致，這段期間網站與 email 都正常運作。
Q11其他單位使用 Cloudflare 是怎麼確認的？
A查詢各網站公開的名稱伺服器（*.ns.cloudflare.com）與網站回應標頭（server: cloudflare、cf-ray）。例如台北榮總、健保署的回應標頭顯示由 Cloudflare 台北節點（TPE）提供服務。查詢時間 2026/11。
Q10原本的 DNS 主機還要保留嗎？
A切換後建議保留一段時間作為退回方案；確認穩定後，可以繼續作為院內 DNS 使用。
