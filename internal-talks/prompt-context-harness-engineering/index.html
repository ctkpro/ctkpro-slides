你到底知不知道
你在跟 AI 說什麼？

Prompt · Context · Harness — 三層，每一層再深挖一階

2026-07-26　｜　Alfred Kang・CTK Pro

先問一個問題——不用回答，也別有壓力

Opus 4.8 跟 4.6，差在哪？
GPT-5.6 跟 5.5 呢？Fable 又是什麼定位？

說真的——這題，連每天在用的人都不一定講得清楚。

而「答不出來」，剛好就是今天的重點——因為真正決定你做得好不好的，根本不在這裡。

換一個更重要的問題

這一兩年變強的
到底是模型，還是你？

跟一兩年前你在跟 ChatGPT、Claude 講話比——
你現在到底知不知道，你在跟 AI 說什麼？

今天這場，就是要把「你在跟 AI 說什麼」這件事，拆成三層、看清楚。

回想你這週跟 AI 的每一次對話

你是「有把握」，
還是在「中獎」？

有把握
意圖、想要的結果、想避開的問題，都想清楚了
context 已經交代夠
知道這次要調用哪些工具、怎麼下
對結果有信心，大概知道它會回什麼
中獎 🎰
你下了命令，卻不知道它回來會變怎樣
剛好做對了，那不是實力
是一種「拉霸中獎」的感覺

「有把握」和「中獎」的距離，就是你對 Prompt、Context、Harness 的掌握。
今天，就是要把你從「中獎」帶到「有把握」。

先破一個聰明人也會有的錯覺

「Prompt 不重要」
是一種錯覺

你覺得「隨便下個 Prompt 也行」，是因為有兩股力量在替你補洞——

  • ①模型腦補模型自己會糾錯，把你沒講清楚的部分猜對了一部分。
  • ②Context 自動補洞對話來回、專案裡的檔案／規範／歷史，把 context 幫你補齊了。

但——補洞 ≠ 精準。僥倖能用，不等於做得夠好。今天，就把這層窗戶紙捅破。

第一層 ｜ Prompt Engineering

Prompt 沒退場
它退到「地基」

心態轉變：不是寫得更長更細，而是把「意圖」講清楚——

  • 給你想要的結果
  • 給這件事的來龍去脈（背景、為什麼要做）
  • 給最後產出該長什麼樣子
  • 但不必給它第一步、第二步的死步驟

把寫 Prompt 當成「把意圖講清楚」的能力，不是「把指令寫細」的能力。
它的一部分責任，會往上長成 Context 和 Harness。

出處：Simon Scrapes〈2026 prompt 建議反轉了〉、IndyDevDan（反對「prompt engineering 已死」）、keynote「Prompt is still a punch card」（2026-07）

第二層 ｜ Context Engineering

Context 會腐化（Context Rot）

  • 累積型Token 累積到 70–80% 之後，開始「掉記憶」、前後不一致漸進發生，你不一定當下察覺
  • 壓縮型Context Window 用滿，系統必然 Compact——一壓縮 100% 掉東西，不是「可能」，是「一定」例如 1M 的 window 被塞滿時

長工作裡，一段被 rot／compact 掉的 context，可能讓整條判斷崩掉——而你甚至沒發現它已經忘了。所以 Context 排在 Prompt 之上。

出處：Manus「KV-cache 命中率是 production agent 最重要指標」、RLM 遞迴壓縮對抗 context rot（folo 6/30・7/02）、Claude Code 70–80% 起 rot（2026-07）

本份的核心洞察之一

Prompt 沒下好
Context 就死得更快

囉唆、失焦的 prompt → 模型燒更多 token 猜你、繞路 → context 更快燒完 → rot / compact 更早報到

所以「把 Prompt 講精準」本身，就是在替 Context 省命。
地基鬆，第二層垮得更快——這就是為什麼第一層是地基。

第三層 ｜ Harness Engineering

Harness＝你是指揮家
不是演奏者

Harness 不只是「你接了哪些工具」，是你手上整套資源——Agent／Skills／MCP・API・CLI——該怎麼「規劃、調度」。

就像聽一首歌：鼓聲先出來，還是吉他先進，還是人聲先唱？
什麼工具、在什麼時序、以什麼力度出場，就是 Harness Engineering。關鍵詞是「有意識地調用」——人退到指揮台，守在「這段該誰上、何時回來問我」的決策點。

出處：Harrison Chase「產業從 framework 轉到 harness」（folo 7/09）、harness＝模型外那層系統（記憶／工具／orchestration，2026-07）

收束：差距在哪裡？

你 vs 同行、你 vs AI
差距收斂成同一件事

  • 你 vs 同行工具一樣、模型一樣——差的是「用得多深」。
  • 你 vs AIAI 越來越能寫、能查、能執行——剩下只有你能做的是：判斷力、決策、意圖的清晰度。

而這三樣不是天生、也不是讀來的——是在一輪輪 Prompt、Context、Harness 裡，被磨出來、長出來的。

差距，就攤在這三個 Level 上

你「在跟 AI 說什麼」，就是在這三層上做選擇；每個選擇，都在長你的判斷、決策、意圖清晰度。

最後，留一個問題給你自己——不用回答我

如果你下的每一個 prompt、餵的每一段 context、搭的每一套 harness，
都只是把客戶的話原封不動搬進去——
那這一整套流程裡，AI 跟你，差在哪裡？

這題，我也常問我自己。而今天講的這三層，就是那個「差在哪裡」的答案——
它是你從「搬運」，長到「判斷」的那條路。

別問哪顆模型強——
問你自己：
你知不知道，你在跟 AI 說什麼？

謝謝

Prompt · Context · Harness ——一起把「中獎」練成「有把握」。
